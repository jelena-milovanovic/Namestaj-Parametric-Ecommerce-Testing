## TC-001 — Select a product colour

**Test type:** Functional testing  
**Priority:** Medium  
**Status:** Not Run

### Preconditions
- The website is accessible.
- A product with multiple colour options is available.

### Steps
1. Open https://namestajparametric.com/.
2. Open a product with multiple colour options.
3. Note the currently selected colour and product image.
4. Select a different available colour.
5. Repeat for each available colour option.

### Expected Result
- Each available colour option can be selected.
- The selected option is clearly indicated.
- The product image updates to match the selected colour.
